# SECOND CURSOR (Unity project)

A Unity prototype of a psychological horror game set inside a fictional 1990s OS, where a second cursor fights you for control.

- **The game:** [`Assets/SecondCursor/README.md`](Assets/SecondCursor/README.md) covers setup, controls, what to test, and the architecture.
- **Quick start:** with your Unity project open, double-click [`SecondCursor.unitypackage`](SecondCursor.unitypackage), click **Import**, then press Play. Alternatively, copy `Assets/SecondCursor` into your project's `Assets` folder, or open this folder as a project in Unity Hub.
- **Story bible:** [`Docs/StoryBible.md`](Docs/StoryBible.md).
- **Dev tools (outside Unity):** `DevTools/CompileCheck` (compile against Unity APIs), `DevTools/CoreTests` (`dotnet test`), and `DevTools/Package/make_unitypackage.py` (rebuilds `SecondCursor.unitypackage` from `Assets/SecondCursor`).
